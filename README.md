# Bible Reader content — HU-Hungarian

This repository contains the Bible Reader SD-card content for **HU-Hungarian**.

## Directory layout

- `text/HU-Hungarian/` — all Bible translations and their original nested folder structure.
- `audio/HU-Hungarian/` — audio Bible book folders and chapter MP3s.
- `gospel/HU-Hungarian/` — Gospel files, retaining original names such as `Gospel.txt` and `Gospel.mp3`.

Copy these folders into the root of the Bible Reader `SDCARD` staging directory.
Do not rename files or flatten directories: the firmware expects the original paths.
